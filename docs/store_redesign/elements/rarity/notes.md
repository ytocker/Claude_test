# RARITY element — round 1

Gem badge + 4-tier+mystery language + constellation thread for the CONSTELLATION
store. Authored at SS=4 (one `smoothscale` down), reusing the locked palette and
the `facet_gem` / `draw_const_thread` DNA from `constellation_hi/render_hi.py`.
Pure pygame, both-target safe.

## Sheet layout
- **Row 1** — the five tier reads as large round-brilliant gems on a flat
  card-dark strip (clean value ground), each over its locked tier glow, with the
  tier WORD beneath in its own gem hue (name + colour agree).
- **Row 2** — greyscale proof: Row 1 desaturated by luma. The five collapse to a
  distinct value staircase, so the read survives a colourblind eye.
- **Row 3** — the tapered gold thread + node star shown on placeholder dark card
  corners across three cut variants, on the most-at-risk tiers, plus a
  corner-size epic / mystery / common adjacency strip.

## Tier value ramp (proven in the greyscale strip)
- common — pale lilac-silver, low chroma, high value.
- rare — mid cyan, clearly the darkest-but-one bar.
- epic — saturated violet, dark value (reads heaviest of the cool three).
- legendary — warm gold, brightest + warmest, the deliberate standout.
- mystery — neutral cool silver, nudged a value step darker than common so the
  two pale reads do NOT collapse to the same grey bar; claims no tier hue slot.

Mystery's gem was retuned from (226,232,244) to (198,208,224) for exactly this
separation — verify against common in the proof strip.

## Per-variant (cut geometry; the value ramp is identical across all)
- **A — round brilliant**: 4 kite crown facets + square table on a round girdle. The expected jewel; the reference cut, used for the five hero gems + proof.
- **B — 8-facet brilliant**: octagonal girdle, 8 crown facets value-stepped by clock angle off the top-left light. Most scintillation; sells "precious" hardest.
- **C — marquise**: tall pointed lens (rhombus) with a lozenge table; a directional jewel-cut silhouette that reads distinct from the round at a glance.
- **D — emerald step**: concentric chamfered-rectangle steps; flattest, fewest thin diagonals, so it survives the downscale especially cleanly.

## Epic-vs-mystery muddy check
Both shown on real dark card corners (Row 3) and side by side at corner size
(adjacency strip). Epic stays a saturated violet body with a dark seat; mystery
stays a cool neutral silver — distinct by hue AND value at the smallest size.
